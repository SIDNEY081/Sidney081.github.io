🚀 Flagship Project

SmartGrid PredictAI

Live

Independent data analytics & AI application for utility grid operations: predictive models for transformer failure detection and electricity theft identification, built on synthetic datasets simulating 3,000 transformers, 100,000 meters, and 1,500 feeders.

Python Pandas NumPy Scikit-learn Matplotlib Seaborn Power BI Tableau

Key Features:

  • 📊 ROC-AUC and precision-scored risk models for transformers, meters, and feeders
  • 🔄 Automated data ingestion, scoring, and CSV output pipeline
  • 📈 Power BI / Tableau dashboards for anomaly and failure-risk visualization
  • 🔌 Flask dashboard with login, AI assistant, and PDF maintenance reports
